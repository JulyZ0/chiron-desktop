### 它是什么

- **本地 agent 工具**：桌面端身份绑定 Windows 账户
- **执行隔离是默认值**：工具执行下沉到受限容器；沙箱不可用时**拒绝启动**，不偷偷回退到进程内执行
- **过程可见**：思考、工具调用、本地用量统计、子智能体运行
