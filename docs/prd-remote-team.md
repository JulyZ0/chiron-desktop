## 5. 已定决策（不再讨论）

- **H20**：进程内信封加密 + 可插拔 KMS。`v2:<keyID>:<DEK>:<data>`；KEK 来自 `KMS_KEK_KEYS`
  或 `APP_SECRET` 派生；`/v1/admin/kms/{status,rotate}`；Redis keyset 也只存密文。
- **Kiri 挡位**：`container` 用 Kiri（Docker Engine API），**不内置** Kiri/Docker，按需下载
  + 内嵌 SHA-256 校验；不可用即拒跑；规格不可放宽；Linux 宿主内核，不是 VM；Windows
  命名管道本版不支持。
- **G22** MCP 不并入统一注册表；**G24** 不做定时触发；**G25** 并入 H2。
- **插件化**：不做 Cordis 式"一切皆可替换"；只做能力 seam + 声明式 bundle（候选 E6）。
- **部署形态（2026-11-27）**：本版本只支持 **Windows 桌面端**（Electron + 本机反代），
  用任务计划程序做登录自启 + 崩溃重启；容器/WSL 编排保留为未来选项，不进本版本承诺。
- **P1-3 steer**：顶层会话维持现状；子 Agent 的 run 级入口是功能项 F1，不在可靠性批次里抢跑。

## 7. 功能路线（2026-11-27）

排序依据：**先用上已有后端能力（子 Agent 可干预/可回看）→ 再提升日常开发闭环（工作台）
→ 再做知识/记忆沉淀 → 最后做桌面/团队协作**。可靠性项（L07–L31）与外部验收并行，不占功能批次。

### 波次 F1：多 Agent 控制面（最高优先）

> **F1 已合入**（2026-11-27）：网关 `POST /v1/subagent/runs/{id}/steer` + 引擎内网端点 +
> 子 Agent 面板输入条；归属/终态/队列满/不可达分别有明确状态码，未送达不会显示成功。
> **F2 复核为已具备**：`SubAgentPane`/面包屑/事件回放早已落地，无需再做。
